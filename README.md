# 🚀 LLM Cost Tracker

Welcome! This is a simple tool to track how much money you're spending on AI stuff.

## What Is This?

Ever used ChatGPT, Claude, or other AI tools and wondered: *"Wait... how much did I just spend?"*

That's what this project does. It helps you keep track of your AI costs so you don't end up broke from talking to robots. 💸

## Why?

Because:
- 🤷 You lose track of API costs fast
- 📊 You need to see where your money goes
- 😅 Spreadsheets are boring
- 🎯 Simple tracking = better decisions

## How to Use It

1. Clone this repo
2. Set up your API keys
3. Start tracking your LLM costs
4. Cry a little when you see the bill 

## Features (Right Now)

✅ Track API calls
✅ See your costs
